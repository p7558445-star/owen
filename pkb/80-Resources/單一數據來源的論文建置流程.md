# 單一數據來源的論文建置流程

首次用於 [[Paper1-癌症病人困擾與未滿足需求]]，可套用到所有量性研究論文。

## 原則
所有數字只存在 `stats.json` 一處。正文、表格、圖都從它產生，所以數字不會在改版時漏改。

```
data/*.xlsx ──compute_stats.py──▶ stats.json ──┬─ render.py ──▶ 正文（template 中的 {{placeholder}}）
                                               ├─ make_figures.py ──▶ 圖
                                               └─ generate_docx.js ──▶ 表格 + DOCX
build.py 串起全部；verify.py 檢查文字、表、圖、stats 四者是否一致
```

## 指令
| 目的 | 指令 |
|---|---|
| 新資料重出全文 | `python scripts/build.py --input data/survey_nXXX.xlsx` |
| 草稿浮水印 | `--status preliminary` |
| 不重繪圖 | `--skip-figures` |
| 投稿前一致性檢查 | `python scripts/verify.py` |

## Template 語法
- `{{N}}`、`{{DT_mean}}`：數值 placeholder
- `[[12]]`、`[[3,5]]`、`[[1-4]]`：引用，轉成上標
- `**粗體**`、`_斜體_`

## 經驗教訓（2026-11-18 稽核）
- 這套流程只保護「有寫成 placeholder 的數字」。template 裡寫死的數字仍會過時，而 verify.py 抓不到（見 [[Paper1-數據一致性稽核-2026-11-18]]）。
- 衍生指標（EPV、比例的 CI）也應在 `compute_stats.py` 計算，不要在文字中手算。
- 舊版文字檔要封存，不要留在 `content/`。
- 原始資料 `data/` 不放雲端（本專案 OneDrive 中沒有 data/，做法正確）。
