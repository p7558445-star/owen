# 家醫科住院醫師 EPA 學習評量 — Power BI 模板

分析維度：**年度 × 半年（1–6 月／7–12 月）× EPA1–12 × 職級（R1–R4）× 姓名 × 信賴程度**。
所有年度的原始檔都放在同一個根資料夾（可分子資料夾），按「重新整理」就會一起匯入，不必改模型。

| 檔案 | 用途 |
|---|---|
| `PowerQuery_M.pq` | 資料匯入與清理（參數、維度表、標準化函式、事實表） |
| `DAX_Measures.dax` | 量值（中位數、達標率、同儕比較、半年／跨年變化、資料品質） |
| `範例_EPA_2026.xlsx` | 虛構的範例資料，格式同 2023 年 RAW DATA，可先用來試跑 |

---

## 1. 原始檔格式（兩種都可以）

**寬表**（每人每半年一列，2023 年 `EPA_1120711.xlsx` 的 RAW DATA 就是這種）

| 姓名 | 職級 | 期間 | EPA1：戒菸服務 | … | EPA12：悲傷支持 |
|---|---|---|---|---|---|
| 王小明 | R1 | 上半年 | 3a | … | 2b |

**長表**（每筆評量一列，逐筆匯出時常見）

| 姓名 | 職級 | 評量日期 | EPA | 信賴程度 |
|---|---|---|---|---|
| 王小明 | R1 | 2026/03/15 | EPA3 | 3b |

程式會自動處理以下情況：

- **欄名不同也能辨識**：例如 `NAME／受評者／學員`→姓名，`R／年級`→職級，`評核日期／日期`→評量日期，`信賴等級／等級／Level`→信賴程度。表頭上方有標題列會自動略過。
- **半年怎麼判斷**（依序）：
  1. 有評量日期時看月份：1–6 月為上半年，7–12 月為下半年。民國日期（例如 115/03/15）也能讀。
  2. 沒有日期時，看「期間」或職級裡的 上／下、前／後、H1／H2、1-6／7-12。
- **年度怎麼判斷**（依序）：評量日期 → 「年度」欄（民國年會自動加 1911）→ 檔名中的 20xx → 所在資料夾名稱，例如 `emyway 2026`。
- **信賴程度寫法**：1a、1b、2a、2b、3a、3b、3c、4a、4b、5 都能讀，大小寫、空白、「Level」字樣不影響。只寫主等級（例如 3）也可以，但這類資料沒有 1–10 分數。

> ⚠️ **學年上／下 ≠ 曆年上／下半年。** 2023 年檔案的「R1上」若是指學年上學期（8 月–隔年 1 月），會被當成曆年上半年（1–6 月）。
> 要嚴格照曆年切分，請讓 emyway 匯出**評量日期**，或在檔案裡加一欄「期間」，填「上半年」或「下半年」。

**建議資料夾結構：**
```
D:\OneDrive\01_臨床與行政\milestone_EPA\統整\
 ├─ 202701\emyway 2026\EPA_2026.xlsx
 ├─ 202801\emyway 2027\EPA_2027.xlsx   ← 明年放進來後按「重新整理」即可
```

## 2. 建立步驟（Power BI Desktop）

1. **常用 → 轉換資料**。在 Power Query 編輯器中，依 `PowerQuery_M.pq` 的順序，一個一個用「新增來源 → 空白查詢 → 進階編輯器」貼上程式碼，並把查詢**改成與標題相同的名稱**：
   `資料夾路徑`、`工作表名稱`（參數）→ `dim_EPA` → `dim_信賴等級` → `dim_職級` → `fnEPA_標準化` → `fact_EPA` → `dim_期間` → `dim_住院醫師`
2. 把 `資料夾路徑` 改成實際路徑，按 **關閉並套用**。
3. **模型檢視 → 建立關聯**（全部為多對一、單向篩選）：

   | fact_EPA 欄位 | → 維度表欄位 |
   |---|---|
   | EPA編號 | dim_EPA[EPA編號] |
   | 信賴程度 | dim_信賴等級[信賴程度] |
   | 職級 | dim_職級[職級] |
   | 期間序號 | dim_期間[期間序號] |
   | 姓名 | dim_住院醫師[姓名] |

4. **設定排序依據**：`dim_EPA[EPA標籤]` 依 `EPA編號`；`dim_期間[期間標籤]` 依 `期間序號`；`dim_職級[職級]` 依 `職級排序`；`dim_信賴等級[信賴程度]` 依 `分數`。
5. **建立達標門檻參數**：模型 → 新增參數 → 數值範圍，名稱 `達標門檻`，範圍 1–5，增量 1，預設 4。
6. 建一張空白表 `_量值`，把 `DAX_Measures.dax` 的量值逐一建立在這張表上。
7. 調整 `dim_職級` 中的 **期望主等級**（預設 R1=3、R2=3、R3=4、R4=4，這只是佔位值），改成科內共識。
8. **另存為 → Power BI 範本 (.pbit)**。範本只存結構、不存資料；每年開啟範本、確認路徑後重新整理即可。

## 3. 建議報表頁面

篩選器（同步到所有頁面）：`dim_期間[年度]`、`dim_期間[半年標籤]`、`dim_職級[職級]`、`dim_住院醫師[姓名]`、`dim_EPA[EPA標籤]`。

| 頁面 | 視覺效果 | 欄位與量值 |
|---|---|---|
| **1 總覽** | KPI 卡片 | 受評人數、評量筆數、分數中位數、達標率、評量覆蓋率 |
| | 矩陣熱圖 | 列 = EPA標籤，欄 = 職級，值 = 分數中位數（設定格式化條件：背景色階） |
| **2 信賴等級分布** | 100% 堆疊橫條圖 | Y = EPA標籤，圖例 = 主等級說明，值 = 等級占比；小倍數 = 職級 |
| **3 上下半年比較** | 群組橫條圖 | Y = EPA標籤，值 = 上半年平均分數、下半年平均分數 |
| | 表格 | 姓名、職級、半年成長（格式化條件：負值標紅） |
| **4 個人歷程** | 折線圖 | X = 期間標籤，Y = 平均分數，圖例 = EPA標籤（單選姓名） |
| | 矩陣 | 列 = EPA標籤，值 = 平均分數、同職級平均分數、與同儕差、同職級百分等級 |
| **5 需關注名單** | 矩陣 | 列 = 姓名，欄 = EPA標籤，值 = 低於期望（1 標紅）；另加一欄 低於期望EPA數 |
| **6 資料品質** | 卡片＋表格 | 未對應等級筆數、缺期間筆數、缺職級筆數；依 來源檔案 分組 |

## 4. 統計解讀注意事項

- **信賴等級是順序尺度**：1a–5 轉成 1–10 分只是編碼，各級之間不一定等距。主要指標請看**中位數、等級分布、達標率**；平均分數只當輔助，例如畫趨勢線時參考。
- **樣本數很小**：每個職級每半年約 3–6 人，同一格（職級 × EPA × 半年）的差異容易被少數人左右。看圖時請一起看 n（評量筆數），不要對 0.5 分的差距過度解讀。
- **評分者效應**：寬表是彙整後的結果，看不到評分者是誰。若 emyway 能匯出逐筆資料（含評量者），建議改用長表格式，之後才能檢查不同評分者的寬嚴差異。
- **前瞻建議**：累積 3 年以上資料後，可以把「人」當隨機效應，以職級、半年、EPA 為固定效應，建立**縱貫順序迴歸模型**（cumulative link mixed model，例如 R 的 `ordinal::clmm`），估計各 EPA 的成長曲線與期望達標時間，作為 CCC（臨床能力委員會）判定的佐證。Power BI 負責呈現與篩查，正式推論建議在統計軟體中進行。

## 5. 常見問題

- **重新整理後某個檔案沒有資料**：通常是找不到表頭列（表頭需含「姓名／NAME／受評者／學員」之一，且至少有 3 個非空儲存格），或工作表名稱不對。在 Power Query 中把 `fact_EPA` 的 `WithData` 步驟裡的 `try … otherwise` 暫時拿掉，就能看到錯誤訊息。
- **同名同姓**：模型以姓名當鍵值。若有同名的人，請在原始檔加上學號等識別欄，並一併修改 `dim_住院醫師`。
